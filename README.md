# University Learning Management & Academic Portal

A full-stack university platform designed to centralize academic
and learning activities for students, doctors, and administrators.

## Tech Stack

### Frontend

- React
- TypeScript
- Vite

### Backend

- Node.js
- Express.js
- TypeScript

### Database

- PostgreSQL
- Prisma ORM
